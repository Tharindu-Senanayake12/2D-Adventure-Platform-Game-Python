🌿 Jungle Escape – 2D Platformer

Jungle Escape is a 2D adventure platformer built with Python and Pygame.
Guide a lost explorer through a jungle filled with dungeons, puzzles, and enemies to survive and escape.

🎮 Features

Player movement: walk & jump

Enemy AI and combat

Puzzle and dungeon challenges

Layered jungle backgrounds

Collectibles, score, and lives

🛠 Technologies

Python 3.x

Pygame

🚀 How to Run
git clone https://github.com/<your-username>/Jungle-Escape.git
cd Jungle-Escape
pip install pygame
python main.py
